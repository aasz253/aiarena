# AI ARENA: HUMAN VS MACHINE
> *"Outthink the Machine. Secure the Future."*

**AI Arena** is a premium, competitive cyber-technology gaming platform where human players battle an intelligent synthetic rival named **NEXUS** across four high-stakes technical disciplines:

1. **AI DevSecOps**: CI/CD pipeline lockdown, container breakouts, Kubernetes admission defense, and agentic LLM tool execution security.
2. **Cybersecurity**: Spear-phishing email headers, SIEM authentication logs, DMZ network firewall topology, and Cloud IAM privilege escalation containment.
3. **Malware & Virus Analysis**: Shannon entropy dissection, Win32 process injection decompilation, EDR process lineages, and ransomware heuristics.
4. **Coding Challenges**: Algorithmic port scan sweeps, defensive input sanitizers, Kubernetes Policy-as-Code admission validators, and cryptographic JWT verification.

---

## Key Features

- **Sentient AI Rival (NEXUS)**: Deterministic local AI opponent with 4 difficulty levels (Rookie, Analyst, Expert, Elite) featuring simulated solving rates, dynamic progress telemetry, and contextual esports banter.
- **Tournament Modes**:
  - **Quick Match**: 3-round speed battle in any chosen discipline.
  - **Ranked Battle**: High-stakes Elo-rated competition impacting global standing.
  - **Cross-Discipline Gauntlet**: The signature 4-round tournament spanning all 4 disciplines back-to-back.
  - **Practice Lab**: Zero-risk sandbox mode with instant expert explanations, hints, and retries.
- **Transparent Scoring Engine**:
  - Base correctness points (100–180 pts).
  - Difficulty multipliers (up to 1.55x on Elite).
  - Deep forensic evidence discovery bonus (up to 30 pts).
  - Capped speed bonus (up to 30 pts) that never outweighs security correctness.
  - Penalties for unsafe security decisions (-25 pts).
- **Persistent Player Progression**:
  - 10 Player Ranks (Rookie → Script Runner → Security Apprentice → Junior Engineer → Cyber Analyst → DevSecOps Engineer → Threat Hunter → Security Architect → Elite Operator → Arena Champion).
  - Sector skill ratings and overall Arena Rating (Elo benchmark).
  - Achievement system and Customization Armory (unlockable titles, themes, avatars).
- **Web Audio API Synthesizer**: Native in-browser synthesized chimes, countdown beeps, alert buzzers, and victory fanfare with zero external audio assets.
- **Offline / Local First**: 100% playable without external API keys or paid services; enhanced with server-side Gemini 3.8 Flash commentary when configured.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Variables
Copy `.env.example` to `.env` (optional):
```bash
cp .env.example .env
```
*Note: The core game functions entirely offline without a Gemini API key. If `GEMINI_API_KEY` is supplied, the server uses Gemini 3.8 Flash for dynamic AI rival commentary and hints.*

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 4. Build for Production
```bash
npm run build
```

### 5. Run Game Engine Tests
```bash
npm run test
```
